# Транспорт: игрок Sam в машинах других игр

Ветка ядра: `physics::Ride` (`core/sam/Physics.*`) и сообщения `ride` / `steer` ([PROTOCOL.md](PROTOCOL.md)). Первый
транспорт — лодки Minecraft (SemCraft 2); модель общая для любого гостя.

## Кто чем владеет

| Что | Владелец | Другая сторона |
|---|---|---|
| Машина: её физика, положение, вода/рельсы/дорога | **гость** | Sam её не видит как сущность — только место сиденья |
| Игрок в машине: положение | **гость** (сиденье) | Sam держит своего игрока на сиденье (`physics::Ride`) |
| Взгляд игрока | **Sam** (мышь) | поворот машины поворачивает взгляд на столько же |
| Клавиши движения | **Sam** | идут гостю как его собственные клавиши: каждая машина рулится, как в своей игре |
| Сесть / встать | **гость** (его правила: ПКМ по лодке, присед) | Sam узнаёт по `ride on/off` |

## Поток

1. Игрок садится по правилам гостя (в MC — ПКМ по лодке в режиме стройки). Двойник в MC теперь ставит машина, а не
   камера Sam (`PlayerSync` пропускает его).
2. Каждый тик гость шлёт `{"t":"ride","on":true,"kind":"oak_boat","p":[сиденье, Sam],"v":[скорость, м/с],"yaw":курс}`.
3. Sam (`physics::Ride` → `Step`): сиденье сейчас = `p + v·задержка`; скорость игрока = `v + (сиденье − игрок)·10`
   (через `Driver`, против гравитации Sam). Дальше 6 м — переставить сразу. Изменение `yaw` поворачивает взгляд.
4. Клавиши Sam (вперёд/назад/влево/вправо, прыжок, присед) → `{"t":"steer","f","s","jump","down"}` 20 раз в секунду
   при изменении; гость нажимает свои клавиши. Ходьба, элитры и плавание Sam в это время выключены.
5. Встать — правило гостя (в MC присед); гость шлёт `ride off`, Sam отпускает игрока.

## Проверено

`SemCraft2/tools/test_physics.py boat` (TFE, Аллея): канал воды MC, лодка, `ride @p mount ...` — Sam сел, вперёд
2.5 с — проплыл 18.7 м по каналу, `ride @p dismount` — встал. Картинка от третьего лица: Стив гребёт в лодке.
