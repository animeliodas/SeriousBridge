# План

Каждый шаг закрывается оракулом — скриптом, который запускает реальные игры и печатает PASS/FAIL. Порты — в своих
репозиториях; общее переезжает в ядро.

## 1. Протокол и стенд
- [x] Модель владения и протокол из SemCraft 2 ([ARCHITECTURE](ARCHITECTURE.md), [PROTOCOL](PROTOCOL.md)).
- [x] `tools/echo_guest.py` — минимальный гость.

## 2. Ядро на стороне Sam
- [x] `core/sam`: аллокатор, игрок, физика, dev-хук; для гостей рядом — связь, экспорт уровня, муверы, монстры,
      оружие, твёрдое гостя, вклейка кадра. Подключается `SeriousBridge.props`; порт задаёт `SB_NAME`.
- [x] SemCraft 2 и SeriousPortal собираются поверх ядра; их оракулы проходят.
- [ ] Порт связи (25610), имя памяти кадра — настройки порта (сейчас в коде гостя SemCraft 2).
- [ ] Несколько портов в одной игре: общий хост ядра (сейчас каждый порт держит свою копию — двое не должны вести
      одну и ту же механику, например скорость игрока; SemCraft 2, SeriousPortal и SeriousHL вместе проверены).

## 3. Физика ([PHYSICS](PHYSICS.md))
- [x] Силы по ID (импульс, сдвиг, телепорт), режим движения против гравитации Sam (`Driver`), вид игрока.
- [x] Монстры: отдача от ударов и взрывов гостя (`actorhit.kb`), поршни.
- [x] Движение игрока по правилам другой игры целиком (`Movement`): Half-Life в SeriousHL.
- [ ] `Driver` для любой сущности: монстры Sam в воде гостя, на его транспорте.
- [ ] Обратно: физика Sam для мобов гостя (прыжок Сэма, его гравитация).

## 4. Транспорт ([TRANSPORT](TRANSPORT.md))
- [x] Езда на транспорте гостя (`physics::Ride`, `ride`/`steer`): лодка Minecraft — проверено.
- [ ] Вода уровней Sam как вода гостя (лодки по озёрам Sam).
- [ ] Вагонетки, лошади MC — путь тот же, проверить.

## 5. Порты
- [x] **Minecraft** — SemCraft 2 (гость работает рядом).
- [x] **Portal** — SeriousPortal (правила гостя переписаны, ассеты — с установки игрока). Дальше: кубы и кнопки,
      рекурсивная картинка, пушка как оружие Sam.
- [x] **Half-Life** — SeriousHL: движение HL1 (бег, стрейф, банихоп, присед, даксы, бусты от урона), оружие HL на
      стволах Сэма; сборка для спидрана с таймером RTA/IGT и LiveSplit. Дальше: полный перенос (сэтчел, трипмина,
      арбалет, эгон, хорнет-ган, броня HEV, анимации перезарядки, вода по HL) — всё, кроме монстров и карт.
- [x] Инструменты спидрана в ядре (`Speedrun`): таймер RTA/IGT, сплиты, LiveSplit.
- [ ] **Doom** (классический). План: исходный порт GZDoom (GPL) как гость рядом — его рендер в общую память, как у
      SemCraft 2, монстры и оружие Doom в уровнях Sam; WAD с установки игрока, для разработки — свободный
      [Freedoom](https://freedoom.github.io). Нужна своя копия Doom (в библиотеке Steam сейчас только DOOM: The Dark
      Ages — это другая, сетевая игра, её не трогаем). Вторая сторона ядра — гостевая (`core/guest-*`): общее для
      гостей, которые рендерят рядом (связь, двойник игрока, камера, кадр в общую память).

## 6. Сэм в другой игре (обратный мост)
- [ ] Механики Sam как гость: монстры Sam (их ИИ и урон считает Sam, хозяин рисует и сталкивает), оружие Sam в руках
      игрока хозяина. Первый хозяин — Minecraft.

## Правила
- Только одиночная игра или свои серверы, никаких онлайн-игр с античитом.
- Никаких файлов игр в репозиториях; ассеты берутся с установки игрока.
- Тест-стенды не трогают сохранения игрока (копия `SaveGame` перед запуском).
