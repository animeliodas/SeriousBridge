# Архитектура моста

Описание по работающему мосту SemCraft 2 (Serious Sam Classic ↔ Minecraft 26.3). «Хозяин» — игра, в которой играет
человек (у неё фокус, её окно видно); «гость» — игра, работающая рядом со спрятанным окном.

```
Serious Sam Classic (хозяин)                                   гость (Minecraft, ...)
  SeriousSam_Custom.exe + Classics Patch 1.9.4                   процесс гостя + мод/плагин гостя
  плагин моста (C++ v143, x86)                                   адаптер гостя
    камера ─────────────── связь: WebSocket JSON 127.0.0.1 ────▶   камера гостя = камера Sam
    уровень ────────────── файлы %TEMP%\<мост>\level_<hash>.tri ▶   невидимая оболочка уровня у гостя
    оружие, снаряды, монстры ─────────────────────────────────▶   урон, взрывы, «двойники» монстров
    урон, толчки, вода, поршни, твёрдое ◀──────────────────────    события мира гостя
    вклейка кадра (OpenGL, глубина) ◀── общая память (цвет, глубина, слой HUD/экранов)
    ввод экранов (курсор, клики, клавиши) ────────────────────▶   экраны гостя (инвентарь, чат, сундуки)
```

## Владение

| Что | Владелец | Другая сторона |
|---|---|---|
| Игрок: положение, взгляд, физика | хозяин (Sam) | у гостя — «двойник» без своей физики, ставится в глаза Сэма каждый кадр |
| Камера | хозяин | камера гостя принудительно та же (поза, FOV, аспект) |
| Геометрия уровня | хозяин | у гостя — невидимая оболочка (вокселизация треугольников уровня) |
| Здоровье игрока | хозяин | гость показывает его; урон гостя по двойнику уходит хозяину |
| Монстры, снаряды, триггеры, сохранения | хозяин | гость видит монстров как невидимых двойников; удары по ним уходят хозяину |
| Мир гостя (блоки, мобы, предметы) | гость | рисуется в кадре хозяина с глубиной; твёрдое — коллизия у хозяина |
| Ввод | окно хозяина | хозяин пересылает гостю только нужное (режим стройки, экраны) |

Правило: у каждой сущности один владелец; другая сторона держит копию и шлёт владельцу запросы (урон, толчок,
перемещение), а не меняет копию сама.

## Каналы

1. **Связь** — WebSocket, текстовые кадры JSON, `127.0.0.1`. Гость — сервер, плагин хозяина — клиент
   (переподключается раз в секунду; порядок запуска любой). Неизвестные `t` игнорируются.
2. **Кадр** — именованная общая память: несколько слотов, у каждого счётчик `seq` (нечётный во время записи),
   цвет RGBA8 (премультиплицированный), глубина float32, слой HUD/экранов. Хозяин берёт слот, только если `seq`
   чётный и не изменился после копирования, и перепроецирует картинку с камеры, для которой она снята, на текущую.
3. **Геометрия** — бинарные файлы, которые пишет хозяин и объявляет по связи: `.tri` (треугольники уровня с
   флагами «подвижный», «проходимый»), `.mov` (подвижные браши в своих координатах).

Подробно — [PROTOCOL.md](PROTOCOL.md).

## Ядро хозяина (Sam) — `core/sam` этого репозитория

Общее для всех портов живёт здесь и компилируется в DLL каждого порта (`SeriousBridge.props`); список модулей — в
[README](../README.md). Порт добавляет своё: правила своей игры (SemCraft 2 — элитры и вода Minecraft, сообщения его
мода; SeriousPortal — порталы и их отрисовка) и своё имя (`SB_NAME`).

| Порт | Чем пользуется из ядра |
|---|---|
| SemCraft 2 (гость рядом) | всем: связь, экспорт уровня, муверы, монстры, оружие, твёрдое гостя, вклейка кадра, игрок, физика (элитры, вода, лодки, отдача, поршни, жемчуг), dev-хук |
| SeriousPortal (правила гостя в плагине) | аллокатор, игрок, физика (телепорт со скоростью), dev-хук |

## Адаптер гостя — своё у каждой игры

Что каждый гость делает сам (в SemCraft 2 — Fabric-мод Minecraft): двойник игрока, принуждение камеры, отрисовка в
общую память, оболочка уровня, перевод урона и событий в сообщения, экраны. Для гостя без модов — внешний процесс,
который пишет в память игры, или своя реализация правил гостя без его движка (паттерн «правила гостя headless»).

## Грабли, общие для любых гостей (из SemCraft 2)

- `pa_aRotation` в действиях Sam — накопленный угол: смещение вида надо перечитывать из новой сущности игрока
  (`m_aLastRotation − m_aLocalRotation`), иначе вид прыгает на новой игре или после загрузки.
- Гравитацию игрока Sam флагом не выключить (Player.es возвращает флаг и сбрасывает взгляд): физику гостя вести
  скоростью с вычитанием измеренной гравитации Sam.
- Браши на лету: наружные нормали, `BSCF_OPENSECTOR`, пересборка на месте, сброс кэшей стоящих сущностей.
- Плагин со своим CRT: `new/delete` через аллокатор движка.
- Старт уровня в Sam делает автосейв в слоты быстрых сохранений — тест-стенды должны копировать `SaveGame`.
