# SeriousBridge — перенос механик других игр в Serious Sam Classic (и Сэма — в другие игры)

SeriousBridge — основа для «мостов» между Serious Sam Classic (The First Encounter 1.05, The Second Encounter
1.07, [Classics Patch](https://github.com/SamClassicPatch/SuperProject) 1.9.4) и другими играми. Обе игры работают
одновременно, каждая остаётся собой, а мост переводит между ними камеру, геометрию, урон, физику, ввод и интерфейс.

Первый и пока единственный рабочий мост — **[SemCraft 2](https://github.com/animeliodas/SemCraft2)**: настоящий
Minecraft 26.3 внутри Sam (блоки и мобы в уровнях Sam с глубиной, оружие Sam против блоков, элитры, вода, поршни,
инвентарь и чат Minecraft поверх Sam). Этот репозиторий собирает из него то, что не зависит от Minecraft: модель
владения, протокол, проверочные стенды и план выделения общего ядра.

> Состояние: **документы и протокол, кода ядра здесь ещё нет.** Работающий код — в SemCraft 2; выделение ядра —
> по [ROADMAP](docs/ROADMAP.md). Сделано с помощью Claude Code (ИИ).

## Два направления

1. **Гость внутри Sam** (как SemCraft 2). Sam — хозяин: он владеет игроком, камерой и уровнем. Гостевая игра
   запускается рядом, получает камеру и геометрию уровня Sam, рисует свой мир в общую память, а плагин Sam вклеивает
   его в кадр с глубиной. Урон, толчки, твёрдые блоки, вода и экраны гостя возвращаются в Sam.
2. **Сэм внутри гостя** (обратный мост). Хозяин — другая игра; Sam (или его механики: оружие, монстры, физика
   прыжка) работает рядом и отдаёт состояние. Протокол тот же, роли меняются местами.

## Правила

- Только одиночная игра или свои серверы; никакого вмешательства в онлайн-игры с античитом.
- Никаких файлов игр в репозитории: всё из игр берётся с установки игрока (геометрия уровня Sam экспортируется на
  лету в `%TEMP%`).
- Каждое утверждение «работает» — с оракулом (скрипт, который запускает реальные игры и печатает PASS/FAIL), как
  `tools/test_*.py` в SemCraft 2.
